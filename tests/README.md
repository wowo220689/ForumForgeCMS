# Regression Tests

Requirements: PHP 8.1+ with PDO SQLite and mbstring. Tests create a disposable application copy in the OS temporary directory. They never use the project's installed database.

```sh
php tests/run.php
```

To retain the fixture for HTTP smoke tests:

```sh
php tests/run.php --keep
php -S 127.0.0.1:8133 -t <printed-fixture-directory>
```

In another PowerShell terminal:

```powershell
./tests/http-smoke.ps1
```

The smoke test uses a test-only administrator password generated by the fixture, not production credentials. Stop the development server and remove the temporary fixture after testing.

IP denial tests can set the fixture policy with `php tests/fixture-ip.php <fixture> block` and clear it with `php tests/fixture-ip.php <fixture> clear`. A blocked request to `index.php`, `avatar.php`, or `logo.php` must return HTTP 403.
