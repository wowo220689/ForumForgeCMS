# Regression Tests

Requirements: PHP 8.1+ with PDO SQLite and mbstring. Tests create a disposable application copy in the OS temporary directory. They never use the project's installed database.

```sh
php tests/run.php
```

To retain the fixture for HTTP smoke tests:

```sh
php tests/run.php --keep
php -S 127.0.0.1:8133 -t <printed-fixture-directory>
```

In another PowerShell terminal:

```powershell
./tests/http-smoke.ps1
./tests/http-smoke-1.4.ps1 -FixtureDirectory <printed-fixture-directory> -BaseUrl http://127.0.0.1:8133
```

The smoke test uses a test-only administrator password generated by the fixture, not production credentials. Stop the development server and remove the temporary fixture after testing.

The 1.4 HTTP script runs the baseline smoke checks itself; use it instead of the baseline script for a full run on a fresh fixture. It additionally checks permissions, profile ownership/escaping, notifications, and login lockouts across new sessions.

To test sixteen simultaneous SQLite login reservations, run the following against a retained fixture using PowerShell 7:

```powershell
./tests/login-concurrency.ps1 -FixtureDirectory <fixture> -Php <php-executable> -ExtensionDirectory <php-extension-directory>
```

It expects exactly eight allowed reservations and eight blocked attempts, then clears login guard state only in the disposable fixture. The fixture helpers refuse paths outside the operating system temporary directory or without the test-specific directory prefix.

IP denial tests can set the fixture policy with `php tests/fixture-ip.php <fixture> block` and clear it with `php tests/fixture-ip.php <fixture> clear`. A blocked request to `index.php`, `avatar.php`, or `logo.php` must return HTTP 403.
